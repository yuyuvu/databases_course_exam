# Итоговый проект по дисциплине "Базы данных"

## Описание проекта
Проект выполнен в рамках дисциплины "Базы данных". <br>
Цель - отработка навыков написания SQL-запросов, использования различных синтаксических конструкций SQL и работы с СУБД на схемах данных, схожих с реальными. <br>
В проекте решены задачи по данным четырёх разных баз: транспортные средства, автомобильные гонки, бронирование отелей, структура организации. В каждой задаче для решения требовалось написать один SQL-запрос с использованием различных изученных в процессе прохождения курса конструкций: SELECT, JOIN, GROUP BY, ORDER BY, агрегатные функции, CTE, RECURSIVE и др.

## Использованные инструменты для выполнения проекта
СУБД PostgreSQL 18, <br>
клиент pgAdmin 4, <br>
SQL-скрипты в файлах с расширением ".sql". <br>

Работоспособность всех реализованных нами скриптов и запросов в них была проверена в pgAdmin 4 версии 9.12. 

Для каждой базы данных выделена отдельная директория и подготовлены следующие файлы:
1) скрипт создания таблиц базы данных (tables_creation_script.sql)
2) скрипт заполнения таблиц данными (tables_data_filling_script.sql)
3) файлы с решениями задач (1. task 1 answer.sql, 2. task 2 answer.sql и т.д.) и подробными описаниями каждого решения
4) инструкция по проверке (Инструкция по проверке.txt)

##  Структура баз данных и решённые задачи
#### 1. Транспортные средства
Таблицы: vehicle, car, motorcycle, bicycle. <br><br>
Решено 2 задачи: <br>

Задача 1 - найти спортивные мотоциклы с мощностью > 150 л.с. и ценой < 20000. <br>
Задача 2 - объединить данные об автомобилях, мотоциклах и велосипедах по разным критериям с сортировкой. <br>

#### 2. Автомобильные гонки
Таблицы: classes, cars, races, results. <br><br>
Решено 5 задач: <br>

Задача 1 - поиск автомобилей с наименьшей средней позицией в каждом классе. <br>
Задача 2 - поиск лучшего автомобиля по средней позиции. <br>
Задача 3 - поиск классов с наименьшей средней позицией, а также всех их автомобилей. <br>
Задача 4 - поиск автомобилей, чья средняя позиция лучше средней по классу (в классах с количеством авто >= 2). <br>
Задача 5 - поиск классов с наибольшим числом автомобилей, имеющих среднюю позицию > 3.0. <br>

#### 3. Бронирование отелей
Таблицы: hotel, room, customer, booking. <br><br>
Решено 3 задачи: <br>

Задача 1 - поиск клиентов с количеством бронирований > 2 в разных отелях, вывод списка отелей и средней длительности пребывания в днях. <br>
Задача 2 - поиск клиентов, удовлетворяющих условиям > 2 бронирований, > 1 отеля, потрачено > 500. <br>
Задача 3 - категоризация отелей (дешёвые, средние, дорогие) и определение предпочтений клиентов. <br>

#### 4. Структура организации
Таблицы: departments, roles, employees, projects, tasks. <br><br>
Решено 3 задачи с использованием рекурсивных запросов: <br>

Задача 1 - нахождение всех подчинённых генерального директора Ивана Иванова с выводом их проектов и задач. <br>
Задача 2 - условие задачи 1 с дополнительным определением количества задач и количества прямых подчинённых. <br>
Задача 3 - поиск менеджеров, имеющих подчинённых, с выводом проектов, задач и общего числа подчинённых. <br>

## Подход к решению задач
При решении задач мы старались придерживаться принципов читаемости, модульности и наличия документации. <br>
Каждый запрос разбит на логические блоки. Сначала описывается условие задачи, затем идёт сам код запроса. В конце каждого сложного скрипта дополнительно описываются принятые решения и раскрывается логика запроса. Блоки запроса для читаемости разбиваются по смыслу новыми строками или отступами. Добавлены сокращения при помощи ключевого слова as. <br>
Cложные запросы структурированы при помощи обобщённых табличных выражений (CTE), что позволило сделать сложные запросы полностью читаемыми, не добавляя вложенность. Также каждый файл решения содержит подробные комментарии к каждой строке запроса. <br>
Все решения были проверены на предоставленных данных, результаты точно соответствуют ожидаемым (в комментариях также раскрыты отдельные моменты, когда ожидаемый вывод расходился с условием задач, и какие решения нами были в связи с этим приняты).

## Инструкция по запуску и тестированию
Для каждой базы данных: <br>
1) Откройте соответствующую директорию в файлах скачанного репозитория. <br>
2) Откройте pgAdmin 4. <br>
3) Создайте новую базу данных с соответствующим именем (exam_vehicles, exam_car_races, exam_hotel_booking, exam_organization_structure). <br>
4) Откройте Query Tool и подключитесь к созданной базе. <br>
5) Откройте файл tables_creation_script.sql (через Open File, Ctrl + O) и выполните его (Execute Script, F5) для создания таблиц базы. <br>
6) Откройте файл tables_data_filling_script.sql и выполните его для заполнения таблиц базы данными. <br>
7) Аналогично последовательно открывайте и выполняйте файлы решений задач к данной базе данных - "1. task 1 answer.sql", "2. task 2 answer.sql" и т.д. <br>
<p>Каждый файл соотвествует одной задаче, содержит описание решения, его выполнение выводит решение задачи. <br>
