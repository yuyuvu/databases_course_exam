Откройте программу pgAdmin 4.

Создайте базу данных c названием exam_organization_structure через интерфейс или при помощи запроса CREATE DATABASE exam_organization_structure.

Откройте query tool в pgAdmin и выберите подключение к созданной базе данных exam_organization_structure.

Откройте файл tables_creation_script.sql через функцию Open File (Ctrl + O). Выполните его для создания таблиц базы через функцию Execute Script (F5).

Откройте файл tables_data_filling_script.sql через функцию Open File (Ctrl + O). Выполните его для заполнения таблиц базы данными через функцию Execute Script (F5).

После этого последовательно открывайте и выполняйте 3 файла из данной папки с названиями типа "1. task 1 answer.sql", для проверки решений к каждой задаче для данной базы данных. Каждый такой файл содержит решение к отдельной задаче. В каждом файле содержатся комментарии, раскрывающие логику решения задачи.
